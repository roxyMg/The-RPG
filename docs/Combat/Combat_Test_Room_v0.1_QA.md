## 发现并修复

1. 首次 Prefab 生成使用 JSON 复制标量字段时，精英检测点引用未正确保存。改为显式绑定 Prefab 内部 Transform，并新增保存后引用校验；复测站地、追击及全部攻击通过。
2. 编辑器沿用“禁用 Domain Reload”与控制台错误暂停配置，首次失败的批处理可能停住。测试入口新增明确的运行器注入、暂停恢复和超时退出；不更改正式编辑器设置。
3. 无前台窗口的批处理鼠标注入不能证明输入路由。改为自动测试实际 FSM / Animator / 伤害链路，单独进行独立程序输入验收。
