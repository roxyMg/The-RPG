本文件是任务状态的唯一维护位置。模块盘点是现状说明，素材台账是资源状态，验收记录是测试证据，不重复维护任务进度百分比。

## 状态与优先级

- 待规划：范围或产品决定未定；待办：已明确但依赖未完成；就绪：可以开始；进行中：有人在执行；待验收：实现完成且需要测试；受阻：必须写明原因与解除条件；已完成：验收通过并留下记录。
- P0：阻止运行、核心流程或交付，需要优先排查；P1：本版核心玩法和体验；P2：完善或后续内容。
- 未领取任务的负责人为“未分配”，期限为“未设”。领取时在任务详情填写实际负责人和日期。同一时间最多 2 项进行中。
- 新发现的问题用下一个 DEMO 编号加入表格，写复现、预期、实际结果和证据。不要因“脚本已存在”直接标完成。
